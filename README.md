# DroAIVC · 节水抗旱虚拟细胞

21 个物种的单细胞转录组图谱与干旱响应预测静态门户。

- 在线站点：https://ddxxz.github.io/DroAIVC-portal/
- GitHub 仓库：https://github.com/ddxxz/DroAIVC-portal
- 图件：`media/full` 为 2200px JPEG 预览，`media/thumb` 为 640px 缩略图，`media/pdf` 为原始 PDF。
- 数据：`data/` 中包含图件清单、统计与轨迹/GRN 交互数据。
- 完整原始图件：（可选：在 GitHub Release 中提供原始图件包）
- 本地预览：在仓库根目录运行 `python3 -m http.server 8000`，打开 `http://127.0.0.1:8000/`。

公开版为优化预览；模型预测、轨迹、GRN 与扰动均为计算推断，不作为实验证据。
